# GitHub skills shortlist: SEO, design, funnel attribution

Vetted 2026-09-13 by reading each repo's README and the SKILL.md of every contested candidate. Overlapping skills were grilled and cut to one winner per capability. The winners' "needs from the client" column is what `/kickoff` collects on the client Google Meet. Check this page before installing any skill. Nothing here is installed yet; see "Install order" at the bottom.

## Vetting checklist (apply to any skill repo)

- `SKILL.md` with `name` and `description` frontmatter, same shape as `.claude/skills/*/SKILL.md`.
- Works with no paid API, or the paid part is an optional extension.
- MIT or Apache-2.0. Commit in the last 90 days. Not marked discontinued.
- Small enough to read every file before install. Read `scripts/` and `install.sh` for network calls first.
- Built for lead-gen and local service businesses, not SaaS signup funnels. SaaS-only skills get cut or adapted.
- Plain markdown so `scripts/sync-codex-skills.sh` can mirror it to `.agents/skills/`.
- Advisors only. On conflict, `references/voice.md` and `projects/Landing Page Build/Style Guide.md` win.
- Runtime fits this machine: Python yes, Node no (`connections.md` row 9). Node-only MCPs are blocked until Node is installed.

## UTM standard (proposed, pending Jonathan)

Per client and per channel, lowercase, hyphens: `utm_source=google&utm_medium=cpc&utm_campaign=<service>-<city>&utm_content=<ad-group>`. LinkedIn keeps the template already on `connections.md` row 11. Hidden form fields carry all UTMs into the lead email, the same way `/avmarketing/` does; a calendar link cannot, so the form comes before the calendar on every client page (coreyhaines `attribution`, Pillar B).
