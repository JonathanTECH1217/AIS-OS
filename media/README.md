# Media

Short-form video lives here, worked on in Monarc Studio (Desktop shortcut "Monarc Studio", guide
`references/studio.md`). Git tracks only this file; everything under `media/` is ignored.

- `inbox/`: recordings (cold-call sessions from OBS, phone clips). A new file is prepared automatically: an MP4
  copy, a waveform, a small preview copy, thumbnails and a word-by-word transcript, all on this laptop.
- `sfx/`: sound effects. They show in Studio's Sounds bin (click to hear, drag onto A2).
- `assets/`: logos, screenshots and B-roll for overlay tracks. `assets/brand/` holds the logo set (butterfly, wordmark,
  white wordmark, SVG) and `assets/proof/` the proof photos and the penthouse walkthrough (Jonathan, 2026-10-03:
  "save the logo under media and assets; this is where proof photos should live too"). The plain rough-in photo
  shows the PHA shirt logo; overlay the masked one. Copies: the originals stay in
  `projects/Landing Page Build/brand/export/` and `projects/outreach/proof-pack/`, which other files still point at.
- `projects/`: one file per short (`.versions/` keeps a copy every 10 minutes; `.trash/` holds deleted shorts).
- `ready/`: finished exports (1080x1920, 30 fps, captions burned in, -14 LUFS). The scheduler picks up from here.
- `.studio/`: Studio's cache (about 7 GB per 4-hour recording). Safe to delete; it is rebuilt.
